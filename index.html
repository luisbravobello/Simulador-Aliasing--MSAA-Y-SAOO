TEORÍA Y COMPORTAMIENTO

El Aliasing (efecto escalera o jaggies) ocurre en gráficos por computadora cuando intentamos representar formas continuas (como el fuselaje inclinado y alerones de la nave espacial) en una pantalla compuesta por una grilla discreta de píxeles.

¿Por qué sucede?
Cada píxel de la pantalla sólo puede tomar las coordenadas del centro del píxel. Al muestrear líneas diagonales en las alas de la nave, los píxeles adyacentes cambian abruptamente entre 0% y 100% de intensidad, formando escalones visibles.

En videojuegos arcade 8-bit / 16-bit de naves espaciales (como Galaga o Gradius), el aliasing es característico de los sprites de píxeles. En motores 3D modernos, genera parpadeos y bordes dentados molestos.

CÓDIGO OPENGL / FREEGLUT C / C++ 
// Ejemplo 1: Renderizado con Aliasing activo en OpenGL
void renderSceneAliased() {
    // Desactivar multisampling y suavizado
    glDisable(GL_MULTISAMPLE);
    glDisable(GL_LINE_SMOOTH);

    glColor3f(0.0f, 0.9f, 1.0f); // Cian Nave
    glLineWidth(3.0f);

    glBegin(GL_LINES);
        glVertex2f(-0.8f, -0.4f); // Punto A
        glVertex2f(0.8f, 0.4f);   // Punto B diagonal
    glEnd();
}

CÓMO FUNCIONA EL MSAA

MSAA (Multi-Sample Anti-Aliasing) es una técnica espacial optimizada que reduce los bordes dentados evaluando múltiples puntos de prueba (sub-muestras) dentro de la superficie de cada píxel en las aristas de los polígonos.

Eficiencia clave del MSAA:
A diferencia de SSAA (Super-Sampling), el MSAA no ejecuta el Fragment Shader varias veces por píxel. Solamente evalúa la cobertura geométrica en las sub-muestras y promedia el color final en proporción al porcentaje de puntos cubiertos.

Al seleccionar 4x MSAA, si 3 de 4 submuestras caen dentro del ala de la nave espacial, el píxel se pintará con 75% del color del polígono y 25% del fondo, creando un degradado suave en la silueta.

CONFIGURACIÓN MSAA EN FREEGLUT / OPENGL C / FreeGLUT 
// Inicializar MSAA en la ventana de FreeGLUT
int main(int argc, char** argv) {
    glutInit(&argc, argv);
    // Solicitar Buffer con soporte Multisample
    glutInitDisplayMode(GLUT_DOUBLE | GLUT_RGB | GLUT_DEPTH | GLUT_MULTISAMPLE);
    glutInitWindowSize(800, 600);
    glutCreateWindow("FreeGLUT MSAA Simulator");

    // Activar Multisampling en el Pipeline de OpenGL
    glEnable(GL_MULTISAMPLE);

    // Consultar número de muestras soportadas
    GLint samples;
    glGetIntegerv(GL_SAMPLES, &samples);
    printf("Muestras MSAA activas: %d\n", samples);

    glutMainLoop();
    return 0;
}

OCLUSIÓN AMBIENTAL EN ESPACIO DE PANTALLA

SSAO (Screen-Space Ambient Occlusion) es un algoritmo de sombreado en tiempo real desarrollado por Crytek. Simula cómo la luz ambiental se bloquea en pliegues, grietas y esquinas donde dos superficies están muy cerca.

¿Cómo funciona en espacio de pantalla?
Utiliza el mapa de profundidad (Depth Buffer) y las normales de la geometría. Para cada fragmento, genera muestras aleatorias en una hemisferio y comprueba cuántas quedan "ocultas" detrás de otra geometría cercana.

Al agregar SSAO a la estructura de la nave espacial y hangar, la escena adquiere volumen tridimensional y sombras de contacto reales sin necesidad de Ray Tracing.

FRAGMENT SHADER DE SSAO (GLSL) GLSL / OpenGL 3.3+ 
// Shader Fragmento SSAO Simplificado
uniform sampler2D gPosition; // Textura de Posiciones 3D
uniform sampler2D gNormal;   // Textura de Normales
uniform vec3 samples[64];    // Núcleo de Muestreo Hemisférico

void main() {
    vec3 fragPos = texture(gPosition, TexCoords).xyz;
    vec3 normal  = texture(gNormal, TexCoords).xyz;

    float occlusion = 0.0;
    for(int i = 0; i < 64; ++i) {
        // Obtener posición de muestra en espacio de vista
        vec3 samplePos = fragPos + samples[i] * radius;

        // Proyectar muestra a coordenadas de pantalla
        vec4 offset = vec4(samplePos, 1.0);
        offset = projection * offset;
        offset.xyz /= offset.w;
        offset.xyz = offset.xyz * 0.5 + 0.5;

        // Comprobar profundidad almacenada
        float sampleDepth = texture(gPosition, offset.xy).z;
        if (sampleDepth >= samplePos.z + bias) {
            occlusion += 1.0;
        }
    }
    // Invertir y promediar oclusión
    FragColor = 1.0 - (occlusion / 64.0);
}
